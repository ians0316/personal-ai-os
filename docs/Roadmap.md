# Roadmap

## Done
- ✅ **M1 Core:** chat with Claude, notes, tasks, reminders
- ✅ **M2 Semantic memory:** find notes by meaning, automatic recall
- ✅ **M3 Your files:** PDF, Word, Markdown and text search with citations
- ✅ **M4 Calendar and email:** Google Calendar and Gmail, drafts only
- ✅ **M5 Daily briefing:** morning summary on the Today tab
- ✅ **M6 Desktop app and voice:** Mac app, local Whisper push-to-talk, read-aloud

## Next
- ⬜ **M7 React interface:** move the UI to React + Vite as it grows
- ⬜ OCR for scanned PDFs, plus slides and spreadsheets
- ⬜ Create calendar events after you confirm
- ⬜ A global hotkey that works from any app, a menu-bar icon
- ⬜ Outlook / iCal support
- ⬜ Faster vector search (sqlite-vec) for very large note collections
